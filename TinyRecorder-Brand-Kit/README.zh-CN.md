# TinyRecorder 素材包

完整素材位于 `branding/`。先查看 `branding/preview/brand-overview.png` 与 `branding/README.zh-CN.md`。

将 `branding/xcode/AppIcon.appiconset` 及 `TinyRecorderMenuBar.imageset` 复制进项目资产目录。菜单栏需以 Template 渲染。传统 `.icns` 位于 `branding/macos/`；新版分层素材与导入步骤位于 `branding/icon-composer/`。

重新生成脚本与字体许可证位于 `scripts/`。本包不含已在 Mac 编译验证的 `.icon` 工程。
