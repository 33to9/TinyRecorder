# TinyRecorder Brand Kit

All assets are in [`branding/`](branding/). Start with [`branding/preview/brand-overview.png`](branding/preview/brand-overview.png) and [`branding/README.md`](branding/README.md).

Copy [`branding/xcode/AppIcon.appiconset`](branding/xcode/AppIcon.appiconset) and [`branding/xcode/TinyRecorderMenuBar.imageset`](branding/xcode/TinyRecorderMenuBar.imageset) into the project's asset catalog. The menu bar image must be rendered as a Template image. Classic `.icns` files are in [`branding/macos/`](branding/macos/); the newer layered assets and the import steps are in [`branding/icon-composer/`](branding/icon-composer/README.md).

The scripts that regenerate the assets, and the font licenses, are in [`scripts/`](scripts/). This kit does not include an `.icon` project that has been built and verified on a Mac.
