將 [`branding/xcode/AppIcon.appiconset`](../branding/xcode/AppIcon.appiconset) 及 [`branding/xcode/TinyRecorderMenuBar.imageset`](../branding/xcode/TinyRecorderMenuBar.imageset) 複製到專案的資源目錄。選單列圖示需以 Template 方式算繪。傳統 `.icns` 位於 [`branding/macos/`](../branding/macos/)；新版分層素材與匯入步驟位於 [`branding/icon-composer/`](../branding/icon-composer/docs/README.zh-TW.md)。

重新產生素材的指令碼與字型授權位於 [`scripts/`](../scripts/)。本素材包不含已在 Mac 上編譯驗證的 `.icon` 專案。
