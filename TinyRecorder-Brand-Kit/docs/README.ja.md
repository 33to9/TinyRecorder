すべての素材は [`branding/`](../branding/) にあります。まず [`branding/preview/brand-overview.png`](../branding/preview/brand-overview.png) と [`branding/README.zh-CN.md`](../branding/README.zh-CN.md)（簡体字中国語）をご覧ください。

[`branding/xcode/AppIcon.appiconset`](../branding/xcode/AppIcon.appiconset) と [`branding/xcode/TinyRecorderMenuBar.imageset`](../branding/xcode/TinyRecorderMenuBar.imageset) をプロジェクトのアセットカタログにコピーしてください。メニューバーのアイコンは Template 画像としてレンダリングする必要があります。従来の `.icns` は [`branding/macos/`](../branding/macos/) に、新しいレイヤー素材と読み込み手順（簡体字中国語）は [`branding/icon-composer/`](../branding/icon-composer/) にあります。

素材を再生成するスクリプトとフォントのライセンスは [`scripts/`](../scripts/) にあります。このキットには、Mac 上でビルドして検証済みの `.icon` プロジェクトは含まれていません。
